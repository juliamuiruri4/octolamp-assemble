# Octolamp Assemble

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React 19, TypeScript, Vite, Three.js. Static output and hash routing for GitHub Pages subdirectories.

## Users

People who got the Octolamp kit at GitHub Universe '26, or are curious about it, and want to see how it goes together.

## Product Purpose

A realistic, interactive Octolamp build following `UNIVERSE_ASSEMBLY.md` exactly: unpack the kit, wire the Sparkle Motion Mini, test the LEDs, stick the strip on the outer ring then the inner ring and Mona, assemble, test again, tidy up and pack. A short guide embeds the walkthrough video once.

## Capabilities and Constraints

- The lamp is the first-viewport subject on desktop and mobile; the next action is always one tap away.
- Steps and their order are the guide's. The reflector and board come in only at final assembly.
- Every action can be undone; build is saved locally; a corrupt save is explained, never dropped silently; reduced motion is honored.
- Exactly one click-to-play YouTube embed, in the guide.
- Colors are what the kit has: black and white PLA, green LEDs. No invented colorways.
- No push or deploy before manual review.

## Brand Commitments

GitHub brand: neutrals with GitHub Green (#0FBF3E) in small, purposeful moments. Mona Sans. Hardware colors are product material, not brand.

## Product Principles

- Show the real object. Keep copy short.
- One focused instruction at a time.
